# Personalemappen

Medarbejderens side til dokumenter og kontaktoplysninger. Se `CLAUDE.md`.

    npm install
    npm run dev
    npm run build

Deploy: eget Netlify-site. `.env` er committet (offentlige værdier, som i Worklist), så der kræves ingen variabler i Netlify. Tilføj adressen under Supabase → Authentication → URL Configuration → Redirect URLs.
